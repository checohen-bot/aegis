# Changelog

All notable changes to this repository are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

This changelog records changes to the engineering operating system as a whole —
governance, architecture decisions, domain model, standards, and code — not code
alone.

## [Unreleased]

### Added
- Initial bootstrap of the Aegis engineering foundation.
- Root governance documents: `README.md`, `FOUNDER.md`, `CONTRIBUTING.md`,
  `LICENSE`, `CHANGELOG.md`, and `.gitignore`.
- Architecture Decision Records `ADR-0001` through `ADR-0014`, establishing the
  repository, customer, investment philosophy, brand, business model, platform,
  broker integration, architecture style, model-agnostic AI stance, source-of-truth
  policy, technology stack, V1 scope, Domain-Driven Design with frozen canonical
  objects, and the deferral of event sourcing and CQRS.
- Engineering Bible appendices: canonical glossary, ADR index, and references.
- The frozen canonical domain vocabulary: Portfolio, Holding, Company,
  Investment Thesis, Investment Case, Evidence, Observation, Knowledge, Decision,
  Capital Mission, Risk, Catalyst, Learning Event, Behavior Profile, Policy.
